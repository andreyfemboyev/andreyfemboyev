# Software beyond utility.

**Systems engineering · Experimental software · Computational art**

I explore software both as a functional system and as a medium for artistic expression. My projects range from distributed databases and persistent storage to interactive generative environments.

---

## Selected works

### 01 / antiOS

*An operating system without a purpose.*

![antiOS — Identity](https://raw.githubusercontent.com/andreyfemboyev/antiOS-Linux/main/screenshots/identity.png)

An interactive digital artwork inhabited by seven organisms, evolving through six temporal states. Rust, GPU rendering, synthesized audio, autonomous exhibition mode and high-resolution print export.

[Windows](https://github.com/andreyfemboyev/antiOS-Windows) · [Linux](https://github.com/andreyfemboyev/antiOS-Linux) · [Download for Windows](https://github.com/andreyfemboyev/antiOS-Windows/releases) · [Download for Linux](https://github.com/andreyfemboyev/antiOS-Linux/releases)

### 02 / RaftDB Extended

*Consensus, persistence and the mechanics of distributed data.*

An experimental distributed SQL database with Raft consensus, a custom SQL engine, segmented Bitcask-inspired storage, snapshots and recovery. Dependency-free Python core.

[Source](https://github.com/andreyfemboyev/raftfb_extended) · [Architecture](https://github.com/andreyfemboyev/raftfb_extended/blob/main/ARCHITECTURE.md) · [Benchmarks](https://github.com/andreyfemboyev/raftfb_extended/tree/main/benchmarks) · [Releases](https://github.com/andreyfemboyev/raftfb_extended/releases)

### 03 / KERNEL//LAB

*Build beneath Android.*

Offline-first Android/Linux kernel engineering workbench: Rust CLI, Tauri desktop, build planning and artifact inspection, ABI comparison and panic diagnostics. Early alpha; the synthetic Kbuild fixture is not a full Android kernel build.

[Source](https://github.com/andreyfemboyev/kernel-labs) · [Releases](https://github.com/andreyfemboyev/kernel-labs/releases) · [Portfolio film](https://andreyfemboyev.github.io/portfolio/#kernel-labs)
